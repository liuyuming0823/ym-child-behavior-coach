# 常见行为问题分类与应对方向

> 四大类行为问题分类体系。每类含典型场景、成因分析和应对方向。使用时先按行为特征匹配类别，再按年龄分档定位话术。

## 1. 情绪类

### 典型问题
- 发脾气（大哭、尖叫、摔东西）
- 哭闹（持续哭、要这要那都不满意）
- 闹情绪（不说话、生闷气、不配合）

### 成因分析

| 成因 | 说明 | 年龄特点 |
|------|------|---------|
| 情绪调节能力不足 | 前额叶未发育完全，情绪冲动无法自控 | 2-4 岁最常见，随年龄改善 |
| 需求未被识别 | 饿了、困了、过度刺激、身体不适 | 所有年龄 |
| 自主权受挫 | 想自己做但被限制或做不好 | 2-5 岁高峰 |
| 情绪词汇缺乏 | 知道不舒服但说不出来，只能用行为表达 | 2-6 岁 |
| 模仿环境 | 家长或其他孩子用发脾气表达情绪 | 所有年龄 |

### 应对方向
1. 先联结：蹲下平视，说出情绪命名（"你很生气"）
2. 不在情绪高峰讲道理——等降温到可沟通状态
3. 帮助找替代表达方式："你可以说'我很生气'，不用摔东西"
4. 排查生理需求（饿/困/累/病）——很多时候发脾气只是因为这些
5. 对 2-4 岁：给选择转移；对 5-7 岁：约定冷静后聊；对 8-12 岁：尊重空间再复盘

## 2. 习惯类

### 典型问题
- 作业磨蹭（反复走神、发呆、拖延）
- 挑食（只吃特定食物、拒绝新食物、含饭不咽）
- 入睡困难（不肯上床、上床不睡、反复起来）

### 成因分析

| 成因 | 说明 | 适用问题 |
|------|------|---------|
| 执行功能不足 | 无法自我启动任务、维持注意力、切换任务 | 作业磨蹭 |
| 感官敏感 | 对某些质地/气味/味道过度敏感 | 挑食 |
| 作息紊乱 | 日间活动不足、睡前过度刺激、作息不规律 | 入睡困难 |
| 缺乏结构 | 没有清晰的时间和流程预期 | 作业磨蹭、入睡困难 |
| 焦虑/完美主义 | 怕做错、怕写不好、迟迟不动笔 | 作业磨蹭（5-12 岁） |
| 控制权 | 挑食是孩子少数能完全控制的领域 | 挑食（2-6 岁） |

### 应对方向

**作业磨蹭**：
1. 排查是执行功能不足还是焦虑——前者需要结构支持，后者需要降低压力
2. 用可视化的时间表和任务拆解替代口头催促
3. 番茄钟法：5-7 岁 15 分钟一段，8-12 岁 25 分钟一段
4. 完成后描述性表扬具体行为

**挑食**：
1. 不强迫、不谈判、不奖励吃——这些都会加重对抗
2. 多次暴露：同一食物需要在无压力下出现 10-15 次才会尝试
3. 让孩子参与食物准备过程
4. 保证餐桌上有至少一种孩子接受的食物

**入睡困难**：
1. 固定睡前流程（洗澡→故事→关灯），顺序固定
2. 睡前 1 小时关闭屏幕
3. 日间保证足够的体力活动
4. 排查午睡是否过长或过晚

## 3. 社交类

### 典型问题
- 兄妹/同伴冲突（争抢、吵架、互不相让）
- 打人（生气时打人、兴奋时打人）
- 咬人（2-3 岁常见，情绪激动时咬人）

### 成因分析

| 成因 | 说明 | 年龄特点 |
|------|------|---------|
| 社交技能不足 | 不知道如何用语言解决冲突，行为先于语言 | 2-5 岁 |
| 资源争夺 | 玩具/注意力/空间有限，不会协商 | 2-7 岁 |
| 情绪溢出 | 情绪太大无法用语言表达，身体先行动 | 2-4 岁 |
| 模仿 | 看到他人用打/咬解决问题 | 所有年龄 |
| 语言能力不足 | 想说但说不出，急了就动手 | 2-3 岁（咬人高峰） |

### 应对方向
1. 冲突时先分开双方、保障安全，不在现场做长对话
2. 双方情绪降温后分别听两边的说法——不做裁判做调解员
3. 教替代行为："生气时可以说'我很生气'，不可以打人"
4. 对打人/咬人：立即物理阻止（握住手/抱住），短句制止"停，不可以打人"
5. 2-4 岁：给替代行为和情绪命名；5-7 岁：教协商语言和规则；8-12 岁：讨论冲突解决策略

## 4. 规则类

### 典型问题
- 撒谎（否认做过的事、编造不存在的事）
- 屏幕时间谈判（讨价还价、偷偷超时、不按时关）
- 顶嘴（反驳、争辩、不尊重语气）

### 成因分析

| 成因 | 说明 | 适用问题 |
|------|------|---------|
| 逃避后果 | 害怕被罚所以撒谎，说明之前惩罚过重 | 撒谎 |
| 测试边界 | 试探规则是否真的执行、有没有松动 | 屏幕谈判、顶嘴 |
| 自主权需求 | 用谈判和争辩争取自主权 | 屏幕谈判、顶嘴 |
| 模仿成人 | 看到家长也"善意撒谎"或谈判 | 撒谎、顶嘴 |
| 区分现实与想象 | 2-4 岁无法清晰区分，"撒谎"可能是想象 | 撒谎（2-4 岁） |

### 应对方向

**撒谎**：
1. 先承诺安全："说了实话我不会发火，我们一起想办法"
2. 不设"坦白陷阱"（明知他做了还问"是不是你做的"）——直接陈述事实更有效
3. 2-4 岁的"撒谎"多为想象，不必当真纠正，引导区分"真的"和"想的"
4. 5-7 岁：强调信任的价值，"说实话让我更信任你"
5. 8-12 岁：讨论撒谎的后果对他人的影响

**屏幕时间谈判**：
1. 让孩子参与制定规则——参与制定的孩子更愿意遵守
2. 用可视化计时器，时间到自己关——给他关的选择权
3. 不因谈判而松动——松动一次就会谈判十次
4. 提前 5 分钟预告："还有 5 分钟"——给过渡缓冲

**顶嘴**：
1. 区分"表达不同意见"和"不尊重"——前者鼓励，后者纠正方式
2. "你的意见我听到了，我们可以不同意，但请用尊重的方式说"
3. 不以"顶嘴"为由惩罚——孩子在练习表达和辩论，这是正常发展
4. 5-7 岁：教表达方式；8-12 岁：可以辩论但约定底线是尊重
